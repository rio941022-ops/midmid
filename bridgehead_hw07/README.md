# 高雄橋頭糖廠報導網站（HW07）

## 檔案
- `index.html`：網站內容與語意化 HTML 結構
- `css/hw07.css`：外部 CSS 樣式表（藍綠色主題、Grid System、RWD）
- `images/bridgehead-factory.svg`：本作業製作的糖廠主題示意插畫
- `PROMPT.md`：Vibe Coding Prompt 與部署說明

## 預覽
請以 VS Code Live Server 開啟 `index.html`，或在此資料夾執行：

```bash
python3 -m http.server 8000
```

再瀏覽 `http://localhost:8000`。

## 上線
將整個資料夾上傳至 GitHub，再由 Vercel 匯入該 Repository 部署。詳細步驟見 `PROMPT.md`。
